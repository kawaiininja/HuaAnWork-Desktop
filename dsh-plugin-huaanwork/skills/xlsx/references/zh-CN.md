# xlsx 中文指南

## 技能用途

全面处理 .xlsx/.xlsm 表格文件的完整生命周期：创建带公式与格式的工作簿、生成图表与数据透视、读取与清洗数据、批量修改单元格、条件格式与数据验证。

## 任务—工具对照表

| 任务 | 方法 |
|---|---|
| **创建**或**编辑**（含公式/格式） | `openpyxl` —— 注意下文陷阱 |
| **批量数据**导入/导出 | `pandas`（`read_excel`、`to_excel`） |
| **快速查看**某个工作表 | `markitdown file.xlsx` —— 每个表输出 `## SheetName`；也能读 `.xlsm`。无单元格坐标，不能据此规划编辑 |
| **读取**模型（公式*和*值） | 两次 `load_workbook` —— 见下文陷阱 |

> `openpyxl`、`pandas`、`markitdown` 已预装——不要先跑 `pip install`，直接写脚本导入。仅当导入失败（或 `markitdown` 命令缺失）时才安装缺失的包。

> 下文脚本路径均相对于本技能目录。工具选择速记：动格式和公式用 openpyxl，搬数据用 pandas，只看不改用 markitdown；markitdown 看不到单元格坐标，仅用于快速了解内容，不能作为编辑依据。

## 每个交付物的硬性要求

- 全文使用**专业字体**（Arial、Times New Roman），除非用户另有要求。
- **零公式错误**。只要 `recalc.py` 报告 `errors_found` 就绝不能交付。若认为错误是文件本来就有的，必须证明：用 `data_only=True` 加载*原始*文件查看该单元格。你自己引入的错误和继承来的错误看起来完全一样。
- **写公式，永不写死结果**。写 `sheet['B10'] = '=SUM(B2:B9)'`，而不是 Python 算出的合计值。工作簿必须能在输入变化时重新计算。
- **严格按用户规格执行**。确切的表名、确切的列头、用户明确写出的公式。即使再优雅，一个计算了别的东西的重新设计也是失败的。
- **在读者能看到的位置记录每个假设和硬编码数字**——单元格批注，或表格末尾的相邻单元格。有真实来源要引用（如 `Source: Company 10-K, FY2024, Page 45, Revenue Note, [SEC EDGAR URL]`）；数字来自用户时也要明说。
- **你创建、供他人填写的工作簿**：需要一段简短图例说明哪些单元格要编辑，并提供一行真实格式的示例数据。**被要求编辑现有文件时，绝不要添加示例行**。
- **编辑现有文件：完全遵循其既有约定**。文件约定优先于本指南一切内容。先找到文件指定的输入单元格（通常用特定字体色、填充色或底纹标记），只写这些位置，所有既有公式原样保留。

## 重新计算（含公式的文件必须执行）

openpyxl 写入的公式是**没有缓存值**的字符串。重算之前，所有公式单元格对读取缓存值的一方——`pandas`、`load_workbook(data_only=True)`、大多数预览器——都读出 `None`。

```bash
python scripts/recalc.py output.xlsx [timeout_seconds]   # 默认 30 秒
```

LibreOffice 计算每个公式，文件**原地重写**，并返回 JSON：`status`（`success` | `errors_found`）、`total_formulas`、`total_errors`，以及 `error_summary`（每种错误类型最多列出 100 个单元格；`locations_truncated` 表示截断了多少——以 `total_errors` 为准，不要看列表长度）。修复它指出的错误后再跑一遍。

**返回带 `error` 键而无 `status` 的 JSON，表示根本没有执行重算**——只有这种情况才以非零退出码退出；`errors_found` 退出码是 0，所以**绝不能把"正常退出"当成"工作簿干净"**。

**绿色通过只证明公式*能求值*，不证明它*是对的***。差一格的范围、错一行的引用都会产出干净无错但数字错误的结果。应先写 2–3 个公式，确认取值符合预期，再铺开整个表格。

**跨文件链接的工作簿**：若用 openpyxl 重存后重算，外部链接会丢失。这类公式形如 `='[1]Returns Analysis'!$B$2`——`[1]` 是工作簿外部引用列表的索引，指向*磁盘上的另一个文件*而非工作表。该文件通常不在这里，单元格缓存值是唯一的数据载体；openpyxl 保存时会剥离该值，LibreOffice 重算时无法解析，写出 `#NAME?` 并删除所有链接。`recalc.py` 在这种状态下会拒绝运行——保存前先把那些单元格的值从原文件中复制出来（`--force` 可强制执行并自担损失）。

## 选择能通过验证的公式

LibreOffice 实现的函数比 Excel 少，它无法求值的函数会变成烙在交付文件里的 `#NAME?`。

- **优先使用 Excel 2007 时代的函数**——`SUMIFS`、`INDEX`、`MATCH`、`IFERROR`、`SUMPRODUCT`，无需前缀。
- **6 个 2007 后函数可用，但必须带 `_xlfn.` 前缀**（openpyxl 原样写入公式，而 Excel 内部对 2007 后的函数名带前缀存储，UI 隐藏前缀）：`_xlfn.TEXTJOIN`、`_xlfn.CONCAT`、`_xlfn.IFS`、`_xlfn.SWITCH`、`_xlfn.MAXIFS`、`_xlfn.MINIFS`。裸写必得 `#NAME?`。
- **绝不使用 `XLOOKUP`、`XMATCH`、`SORT`、`FILTER`、`UNIQUE`、`SEQUENCE`**。运行时的 LibreOffice 无论加什么前缀都无法求值。新版本虽能求值，但它们是溢出数组函数，openpyxl 写的文件没有溢出元数据，只有区域左上角单元格有值——且 `recalc.py` 对这种截断结果报 `total_errors: 0`。查找用 `INDEX`/`MATCH`，排序、筛选、去重先在 Python 里完成再写入单元格。
- LibreOffice 解析不了的公式会被**小写**回写——这是 `#NAME?` 之外的一个快速识别信号。

## openpyxl 陷阱

- **读模型需要加载两次**：`data_only=True` 给缓存值但公式消失；默认模式给公式字符串但没有值。一次加载不可能两者兼得。
- **`data_only=True` 下保存是破坏性的**：工作簿已无公式，保存会把每个公式永久替换为字面值。
- **对 openpyxl 刚写出的文件用 `data_only=True` 读，处处是 `None`**——先跑 `recalc.py`。（结果为 `""` 的公式读回也是 `None`。）
- **合并单元格：只写左上角锚点**。区域内其余单元格都是 `MergedCell`，`.value` 只读。
- **`.xlsm` 会丢宏**，除非给 `load_workbook` 传 `keep_vba=True`。
- **含空格的表名在跨表引用中必须加引号**：`='Assumptions Inputs'!$B$5`。不加引号会求值为 `#VALUE!`。
- 交叉表引用写完后逐个核对表名与单元格地址，表名改动后所有引用都要同步更新。

## 财务模型规范

除非用户另有要求，或现有文件已有不同约定。

**颜色**：硬编码输入与情景开关用蓝色文字（`0,0,255`）· 公式用黑色 · 链接到其他工作表用绿色（`0,128,0`）· 链接到其他文件用红色（`255,0,0`）· 关键假设与待用户填写的单元格用黄色填充（`255,255,0`）。

**数字格式**：货币 `$#,##0`，并在表头注明单位（如 `Revenue ($mm)`）· 零显示为 `-`（百分比亦然，如 `$#,##0;($#,##0);-`）· 负数加括号 · 百分比 `0.0%`，**以小数存储**（`0.15` 显示 `15.0%`；存 `15` 会显示 `1500.0%`）· 估值倍数 `0.0x` · 年份存为文本（`"2024"`，绝不能是 `2,024`）。

**结构**：每个假设单独放在有标签的单元格中，由引用它的公式使用（写 `=B5*(1+$B$6)`，绝不写 `=B5*1.05`）· 各预测期的公式保持一致——行中间一个被单独改动的单元格是最常见的静默错误 · 为可能为零的分母加保护。

## 依赖

`openpyxl`、`pandas`、`markitdown`（pip 包，已预装——仅在导入失败或命令缺失时安装）· LibreOffice（`soffice`，沙箱环境由 `scripts/soffice.py` 自动配置）。

## 交付前自查清单

- 公式文件已跑过 `recalc.py`，状态为 `success`（`errors_found` 一律修复后重跑）
- 交付数字经抽样核对：任选 2–3 个公式单元格，手工验证其取值正确
- 用户规格逐项核对：表名、列头、指定公式与要求完全一致
- 每个假设和硬编码数字都有可见的说明（批注或相邻单元格），数字来源已注明
- 编辑现有文件时：只写入指定的输入单元格，既有公式零改动，未添加多余示例行
