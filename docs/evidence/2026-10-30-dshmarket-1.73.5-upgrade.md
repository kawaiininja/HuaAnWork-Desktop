## 6. 边界

- **未跑 Windows 打包**：本轮无 Windows 主机；`dist:win*` 与发行制品校验不在本证据范围（见 AGENTS 债表 Windows 行）。

- **`market:check` 的通过依赖执行时 npm latest 仍为 `1.73.5`**：该命令按设计查询 registry 并与 pin 比较；若 latest 前进，它会 fail-closed 直到 `market:prepare` 重跑。本文件记录的查询时刻是 `2026-10-30T07:00:39Z`，`market:check` 与 smoke 各自独立复现 `1.73.5`。复现本证据时若 latest 已前进，`market:check` 变红是预期行为，不是回归。

- **smoke 不覆盖真机交互**：它证明打包/签名状态/架构/入口完整性，不证明托盘、更新对话框或市场 UI 的真机行为；那些仍属人类核对范围。
